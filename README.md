# MOLDOVA TRUCK SIMULATOR 2D (Euro Truck 2D)

2D симулятор дальнобоя по Молдове на чистом Canvas 2D + Web Audio API.
Работает полностью офлайн, без интернета, без внешних библиотек и оптимизирован для слабых ноутбуков.

## Управление
| Клавиша | Действие |
|---|---|
| **W / ↑** | Газ / Ускорение |
| **S / ↓** | Тормоз (пневматические тормоза) |
| **A, D / ←, →** | Руль (передние колёса поворачиваются) |
| **R** | Переключение на задний ход (R) / передний ход (D) |
| **Пробел** | Стояночный тормоз (ручник) / сдача груза на рампе |
| **T** | Сцепка / расцепка полуприцепа на седле |
| **L** | Переключение фар (Выкл / Ближний / Дальний свет) |
| **Q / E** | Поворотники (Левый / Правый) со звуком реле |
| **F** | Аварийная сигнализация |
| **H** | Пневмогудок (Air Horn) |
| **M** | Биржа грузов (выбор рейса) |

## Быстрый запуск
Выполните в терминале:
```bash
./start.sh
```
Или откройте адрес в браузере: `http://127.0.0.1:4250/`

## Оптимизация для ноутбуков
1. **Frustum Culling**: отрисовываются только дороги и объекты в пределах экрана, остальная карта не нагружает видеокарту.
2. **Zero GC Physics**: физика рассчитывается без выделения памяти в цикле кадров.
3. **Без shadowBlur**: тени отрисованы полигонами без тяжелых фильтров размытия, убивающих FPS на встроенной графике Intel HD / Iris.
4. **Процедурный Web Audio**: звуки двигателя, турбины и пневматики синтезируются кодом без загрузки тяжелых аудиофайлов.
