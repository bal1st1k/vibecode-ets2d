# MOLDOVA TRUCK SIMULATOR 2D (Euro Truck 2D)

2D симулятор дальнобоя по Молдове на чистом Canvas 2D + Web Audio API с дизайном главного меню в стиле **Neon Drift**, **реальной дорожной сетью OpenStreetMap (масштаб ETS2 1:19)** и встроенной **админ-панелью для тестирования**.
Работает полностью офлайн, без внешних библиотек и оптимизирован для слабых ноутбуков.

---

## 🗺 Реальная дорожная сеть OpenStreetMap (ETS2 Масштаб 1:19)
Вместо схематичных линий игра использует полноценную дорожную сеть Молдовы, извлечённую из геоданных OpenStreetMap:
- **15 630 перекрёстков (узлов)** и **18 079 дорожных сегментов (рёбер)** с реальными радиусами поворотов, серпантинами и развязками.
- **164 города и посёлка**, **300 АЗС** (Petrom, Lukoil, Rompetrol, Bemol, Vento) и **7 логистических терминалов**.
- **LOD (Level of Detail)** рендеринга на Canvas:
  - Дальний зум: магистрали и ключевые трассы (`motorway`, `trunk`, `primary`).
  - Средний зум: региональные трассы (`secondary`).
  - Близкий зум: районные дороги (`tertiary`), съезды и развязки (`*_link`).
- **Дорожные щиты и знаки**: M1, M2, M5, R1, R6, R14, R20 и др.
- **Алгоритм A\***: расчёт кратчайшего маршрута по дорожному графу (маршрут Кишинёв — Орхей строго по трассе M2/R6 за 31 мс).
- **Плавное движение грузовика**: кабина и прицеп следуют вдоль криволинейных полилиний рёбер.

## Главное меню (стиль Neon Drift)
При запуске игры открывается дашборд с левой навигационной панелью (Rail) и разделами:
- **В рейс (Главная)**: карточка активного контракта, кнопка «В КАБИНУ», статистика автопарка и живое превью тягача на трассе.
- **Рейсы (Биржа грузов)**: выбор коммерческих контрактов на перевозку вина, яблок, подсолнечного масла и оборудования.
- **Гараж**: просмотр купленных тягачей, технические характеристики и чип-тюнинг двигателя (+40 л.с.).
- **Салон**: покупка новых европейских и отечественных магистральных тягачей (KamAZ, DAF, MAN, Mercedes-Benz, Scania, Volvo).
- **Карта**: интерактивная карта Молдовы с панорамированием, зумом, дорожными щитами и навигацией.
- **Админ-панель 🛠**: режим разработчика с интерактивным телепортом по клику, пресетами, диагностикой и читами.
- **Помощь**: таблица управления и механик симулятора.

## Админ-панель для тестов (Телепорт и диагностика)
Доступна как отдельный раздел в меню, так и **прямо во время вождения** по нажатию клавиши `F1` или `~` (тильда):
1. **Интерактивная карта телепортации**: кликните в любую точку трассы для мгновенного перемещения тягача и полуприцепа.
2. **10 готовых пресетов**:
   - Кишинёв: База Trans-Moldova (Южный хаб)
   - Кишинёв: Рампа погрузки
   - Трасса M2: Начало магистрали (выезд)
   - Трасса M2: Скоростная прямая (замер 0–90 км/ч)
   - Трасса M2: Крутой серпантин (проверка заноса прицепа)
   - Трасса M2: АЗС Rompetrol и стоянка
   - Трасса M2: Орхейские холмы (тяга на подъёме)
   - Орхей: Въездная развязка
   - Орхей: Терминал Orhei Logistics (Северный хаб)
   - Орхей: Рампа выгрузки и сдачи груза
3. **Точные координаты**: перемещение по произвольным X, Y, направлению и начальной скорости (0, 60, 85 км/ч).
4. **Инструменты тягача**: мгновенный ремонт (0% урона), заправка до 100%, накачка пневмосистемы (10.0 bar), сцепка/расцепка, сброс/смена груза, разворот на 180°, ускорение +80 км/ч.
5. **Экономика и карьера**: начисление денег (+50k, +250k MDL), открытие всех тягачей, мгновенная сдача груза.

## Управление
| Клавиша | Действие |
|---|---|
| **W / ↑** | Газ / Ускорение |
| **S / ↓** | Тормоз (пневматические тормоза) |
| **A, D / ←, →** | Руль (передние колёса поворачиваются) |
| **R** | Переключение на задний ход (R) / передний ход (D) |
| **Пробел** | Стояночный тормоз (ручник) / сдача груза на рампе |
| **T** | Сцепка / расцепка полуприцепа на седле |
| **L** | Переключение фар (Выкл / Ближний / Дальний свет) |
| **Q / E** | Поворотники (Левый / Правый) со звуком реле |
| **F** | Аварийная сигнализация |
| **H** | Пневмогудок (Air Horn) |
| **Esc** | Выход в главное меню из кабины |
| **F1 / ~** | Админ-панель с телепортом |

## Быстрый запуск
Выполните в терминале:
```bash
./start.sh
```
Или:
```bash
node server.cjs
```
И откройте в браузере: `http://127.0.0.1:4250/`

## Инструменты и сборка карты
- **Сборка дорожной сети OSM**:
  ```bash
  node tools/build-map.mjs
  ```
  Автоматически скачивает `moldova-latest.osm.pbf` и генерирует `data/moldova-map.json` и `data/moldova-map.js`.
- **Автоматические скриншоты Playwright**:
  ```bash
  node tools/take-screenshots.mjs
  ```
- **Тесты**:
  ```bash
  node tests/test-ets2.cjs
  node tests/test-full-lifecycle.cjs
  node tests/test-osm-routes.cjs
  ```

## Оптимизация для ноутбуков
1. **Frustum / Viewport Culling**: отрисовываются только дороги и объекты в пределах видимости экрана (< 0.8 мс на кадр).
2. **Zero GC Physics**: физика рассчитывается без выделения памяти в цикле кадров.
3. **Без shadowBlur**: тени отрисованы полигонами без тяжелых фильтров размытия, сохраняя 60 FPS на встроенной графике.
4. **Процедурный Web Audio**: звуки двигателя, турбины и пневматики синтезируются кодом.
