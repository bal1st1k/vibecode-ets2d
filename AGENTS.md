Правила git для этого проекта:

1. Один коммит = одна логическая задача. Никаких «complete tasks 1-6».
   Если в промпте несколько пунктов, делай по коммиту на пункт.
2. Формат: тип(область): что сделано [T-номер]
   Типы: feat, fix, perf, refactor, data, test, docs.
   Области: render, map, engine, ui, trucks, nav, tools.
   Сообщение по-русски, в повелительном или описательном стиле, до 72 символов.
   В теле коммита (если нужно): что именно изменилось и какие файлы.
3. Веди файл TASKS.md: таблица ID (T-001...), описание, статус
   (todo/doing/done), хеш коммита. Перед работой над промптом заведи строки,
   после коммита заполни хеш.
4. Перед рискованными изменениями (рендер, физика) создай ветку
   exp/название и работай в ней. В main мержи только когда есть скриншоты
   и тесты проходят.
5. После этапа ставь тег vX.Y-название и добавляй запись в CHANGELOG.md
   (что нового, что исправлено, известные проблемы).
6. Не коммить скриншоты, дампы данных и временные файлы без причины;
   скриншоты складывай в assets/screenshots/ и называй по задаче.
