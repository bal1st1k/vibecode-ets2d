# Руководство для AI-агентов (AGENTS.md)

## Правила git для этого проекта:

1. **Один коммит = одна логическая задача**. Никаких «complete tasks 1-6».
   Если в промпте несколько пунктов, делай по коммиту на пункт.
2. **Формат**: `тип(область): что сделано [T-номер]`
   - Типы: `feat`, `fix`, `perf`, `refactor`, `data`, `test`, `docs`, `chore`.
   - Области: `render`, `map`, `engine`, `ui`, `trucks`, `nav`, `tools`, `pkg`, `agents`.
   - Сообщение по-русски, в повелительном или описательном стиле, до 72 символов.
   - В теле коммита (если нужно): что именно изменилось и какие файлы.
3. **Веди файл TASKS.md**: таблица ID (`T-001`...), описание, статус
   (`todo`/`in_progress`/`done`), хеш коммита. Перед работой над промптом заведи строки,
   после коммита заполни хеш.
4. **Ветки для экспериментов**: перед рискованными изменениями (рендер, физика) создай ветку
   `exp/название` и работай в ней. В `main` мержи только когда тесты проходят и есть скриншоты.
5. **Теги и история изменений**: после этапа ставь тег `vX.Y.Z-название` и добавляй запись в `CHANGELOG.md`
   (что нового, что исправлено, известные проблемы).
6. **Скриншоты**: складывай строго в `assets/screenshots/` и называй по задаче. Папка `screenshots/` в корне запрещена.

## Тестирование

Команда запуска набора тестов:
```bash
npm test
```
Запускает все тесты проекта:
- `tests/test-ets2.cjs` — базовые тесты UI, движка, каталога тягачей, мостов и географии OSM.
- `tests/test-full-lifecycle.cjs` — тесты жизненного цикла, навигации по табам, физики и повреждений.
- `tests/test-osm-routes.cjs` — тесты A* маршрутизации на реальном графе дорог Молдовы.
- `tests/test-job-market.cjs` — проверка совпадения origin/target ID депо и названий на бирже грузов.

## Карта файлов (Архитектура проекта)

- `index.html` — разметка приложения: меню Neon Drift, HUD симулятора, оверлей Route Advisor, админ-панель F1 и вкладка Google Maps.
- `styles.css` — неоновые стили темы Neon Drift, CSS-переменные, макеты и анимации.
- `server.cjs` — локальный HTTP-сервер для игры (порт 4250).
- `package.json` — скрипты запуска `start`, `test` и зависимости разработки (`devDependencies`).
- `src/`
  - `app.js` — контроллер интерфейса, навигация страниц, биржа грузов (`renderJobMarket`), гараж, автосалон и взаимодействие с Google Maps.
  - `map.js` — **единый источник картографических данных**: масштаб `MAP_SCALE` (1:8), ширины дорог `getRoadWidth`, полосность `getEdgeLanes`, A*-навигация, географические слои (`GEOGRAPHY`: реки, границы, леса, мосты `map.bridges`, депо `map.DEPOTS`, АЗС `map.FUELS`).
  - `engine.js` — физический движок грузовика и полуприцепа: кинематика Аккермана, седловое сочленение (`Fifth Wheel`), пневмотормоза, стояночный тормоз `parkingBrake`, одометр и расход топлива.
  - `renderer.js` — тайловый Canvas 2D рендерер: тайловый LRU-кеш (512 world-units, 2 px/unit), пространственные сетки `RoadSpatialGrid`, многослойный рендер дорог, отбойники, разметка и миникарта HUD.
  - `trucks.js` — каталог грузовиков (характеристики, цены, цвета, физические параметры).
  - `audio.js` — процедурный синтезатор звуков мотора, пневматики, поворотников и клаксона через Web Audio API.
- `data/`
  - `moldova-map.json` — граф дорожной сети Молдовы из OpenStreetMap (PBF), оптимизированный и сжатый.
- `tools/`
  - `build-map.mjs` — утилита конвертации OSM PBF в JSON с фильтрацией классов дорог и сжатием графа.
  - `measure-fps.mjs` — Playwright бенчмарк FPS (Кишинёв, M3, Крикова) со скриншотами в `assets/screenshots/`.
- `tests/`
  - `test-ets2.cjs` — комплексные тесты логики игры.
  - `test-full-lifecycle.cjs` — сквозные сценарии профилей и симуляции.
  - `test-osm-routes.cjs` — проверка A*-маршрутизации.
  - `test-job-market.cjs` — проверка контрактов биржи грузов.
- `assets/screenshots/` — верификационные скриншоты рендерера и интерфейса.

## Запреты и архитектурные ограничения

1. **Запрет `shadowBlur`**:
   Категорически запрещено использовать `ctx.shadowBlur` и связанные эффекты размытия теней в цикле рендера `gameLoop`, тайловом кеше и `TruckRenderer`. Размытие Canvas на Linux/Firefox обрушивает производительность до 3 FPS. Неоновые эффекты реализуются исключительно многослойными линиями с разной толщиной и прозрачностью (`alpha`).
2. **Запрет аллокаций в физике и кадре (`gameLoop`)**:
   Запрещено создавать новые объекты (`{}`, `new Array()`, `new Map()`, замыкания) внутри методов `sim.update()`, `renderer.render()`, `_buildTile()` и покадровых функций. Все векторы, временные точки и буферы должны переиспользоваться для предотвращения пауз сборщика мусора (GC jitter).
3. **Запрет копипасты**:
   Дублирование алгоритмов, логики смещения полилиний и конвертации координат строго запрещено. Общая геометрия и утилиты выносятся в соответствующие модули.

## Правило «Один источник `MAP_SCALE` и ширин дорог в `map.js`»

- Константа масштаба мира `MAP_SCALE` (1:8, 1 м = 1.25 px) и методы пересчёта реальных единиц (`unitsToRealMeters`, `unitsToRealKm`, `realKmToUnits`) объявляются и экспортируются **только в `src/map.js`**.
- Запрещено использовать локальные магические коэффициенты (`* 0.1`, `* 0.526`) для одометра, топлива, пинов карты и наград.
- Ширины дорог, полосность и отступы отбойников/разметки задаются исключительно функциями `getRoadWidth()` и `getEdgeLanes()` из `src/map.js`. Ни один другой файл не должен хардкодить ширины дорог или мостов.
